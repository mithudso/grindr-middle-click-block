# Code of conduct

Be decent. Assume good faith, keep criticism about the code, and take
disagreements to evidence rather than volume.

Given what this project touches, one thing is not negotiable: **do not post other
people's identifiers** — profile ids, names, photos, message contents — in issues,
pull requests, or captures. Redact before you share. If a bug report needs a real
id to be reproducible, describe the shape instead, or use the placeholder
convention the repository already follows.

Report a problem by opening a private security advisory or contacting the
maintainer directly.
